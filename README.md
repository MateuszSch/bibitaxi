# BibiTaxi

Gra 3D o driftowaniu na Windows: jazda swobodna, tryb taksówki, garaż z częściami i wspólna jazda przez sieć.

## Pobieranie

Pobierz **BibiTaxi-Setup.exe** z [najnowszego wydania](https://github.com/MateuszSch/bibitaxi/releases/latest) i uruchom.

- Gra instaluje się na koncie użytkownika, bez uprawnień administratora.
- Instalator nie jest podpisany, więc Windows może pokazać ostrzeżenie SmartScreen.
- Zainstalowana gra sama sprawdza, czy jest nowsze wydanie, i proponuje aktualizację w menu.
